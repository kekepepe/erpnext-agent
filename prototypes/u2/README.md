# U2 中文工作台交互原型

2026-10-28，首轮设计稿，等待用户视觉/操作反馈。独立静态 HTML/CSS/ES module，无安装依赖；仅使用合成数据和内存状态，无 ERP API 或数据库访问。刷新重置模拟数据，真实系统保持不变。未接入模块明确为导航预览。

启动：在仓库根目录执行 `python3 -m http.server 8092 --bind 127.0.0.1 --directory prototypes/u2`，打开 http://127.0.0.1:8092 。建议桌面浏览器宽窗口体验固定侧栏，小屏使用左上角菜单。

## 交付

- 工作台：常用操作、按模拟角色筛选的待办、最近访问。
- 采购订单：状态页签、供应商/编号/日期/执行状态筛选、空结果、分页及本页金额。
- 详情/新建：选择供应商、添加商品、数量编辑、金额计算、必填提示、保存、独立角色批准、高额复核/退回、撤销依赖提示、操作记录及未保存提醒。
- 其他模块：导航结构预览，不伪装成可执行的业务功能。
- `assets/list-concept.png` 为生成的设计参考，未获用户最终确认。代码采用相同深蓝侧栏、蓝色主操作、白色表格、浅灰背景和状态色；示例日期/金额/状态及筛选项以 U1 为准，修正参考图中待审批但已有入库的错误。图中供应商名不沿用，统一合成前缀。

## 2026-10-28 验证

IAB 实际操作：进入工作台与采购列表；空结果筛选/重置；新建空表必填提示；选择供应商/商品/保存；切换独立采购经理并批准低额订单；高额订单负责人退回→采购经理转负责人复核→负责人批准。状态与操作记录正确更新。Node 语法检查通过。

实际 IAB 窄窗口截图已查看；表格使用区域横向滚动。尚未取得精确1280×720/390×844两尺寸验收，宽屏与全量键盘/历史导航验收仍待补充。原型不构成 U3 权限、安全、库存或账务验收。浏览器后退/刷新不是持久业务恢复机制；入库草稿、打印、修订及其他模块未接入，不把按钮示意当作完成业务链。
