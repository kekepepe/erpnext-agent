## 4. 状态与动作（高风险词规则）

状态内部键来自 `scripts/phase0-configure-access.py`（九类审批流）：

| 内部键/场景 | 建议显示 | 规则 |
|---|---|---|
| Draft (doc_status 0，未入流程) | 草稿 | 已有，保留 |
| Pending（workflow_state） | 待审批 | 中间流程状态用现有中文键：待负责人复核 / 待业务经理复核 / 待财务复核 / 待财务撤销复核 |
| Approved (doc_status 1) | 已批准 | 即"已提交生效"；不用"已完成"（完成指后续入库/收货/付款执行完） |
| Rejected（流程驳回，doc_status 2） | 已驳回 | 区别于原生 Cancelled |
| Cancelled（原生 doc_status 2，非流程） | 已作废 | 与"已驳回"分开展示 |

高风险词规则：

1. **提交 ≠ 审核**：管家婆"审核"≈ 我们的"提交 + 审批"。展示固定用"提交"（单据生效）与"批准"（审批动作），不把审批按钮改叫"审核"。
2. **取消 ≠ 作废 ≠ 撤销**：草稿废弃用"取消"；已提交单据经流程回退用"撤销/驳回"；原生取消（产生冲销）展示"作废"。三者不互换。
3. **红冲不上 UI**：账务冲减统一用"贷项通知单/退货负数"，避免误当红字发票服务。
4. **可用库存 ≠ 实际库存**：实际库存=账面现存量；可用库存=实际+在途−已分配。报表口径在副标题注明。
5. **应收应付 ≠ 收付款**：应收应付=未结余额（发票−收付款）；收款单/付款单=资金动作单据。
6. **退货三分**：实物退回（负数入库/出库单）、账务冲减（贷项通知单）、退款（收款方向 Payment Entry）分别表达，不得合并为一张"退货单"。
7. **Invoice 副注**：采购/销售发票详情页副注"应付确认/应收确认，非法定开票服务"。
