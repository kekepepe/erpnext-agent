**结论要点（v0.2 修订）：**

1. 管家婆以"入库/出库"为中心命名单据（采购入库单、销售出库单），且采购订单与入库是两张单（S2/S3）；这支持 ERPNext 原生的单据拆分方式。
2. 不再由 S4/S5 的摘要推定金蝶所有产品合并收货、出库与应收应付。新来源 S9 明确区分采购、销售、库存及资金相关功能。国内产品仅提供叫法参考；ERPNext Invoice 可涉及 Update Stock，是否拆单须看当前配置和场景，不能把“永远拆开”写成平台定律。
3. 两家都用"收款单/付款单"表达资金往来动作（S1/S6）；"往来单位"是管家婆对客户+供应商的统称，不宜作单一名词。
4. 同一厂商不同版本叫法有差异（进货单 vs 采购订单管理），选词须固定一套主用语并记录来源，不机械混用。
