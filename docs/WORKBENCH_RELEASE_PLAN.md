## 已启动的 M1 工具

2026-11-04 已执行合成商品主数据导入：`scripts/phase0-migrate-masters.py` 使用原生 REST，只接受 localhost:18081、合成公司和 M1-DEMO 编码。`phase0/migration/items-example.csv` 两行 dry-run 待创建 2，首次 apply 创建 2，再次 apply 创建 0、已有一致 2。缺失单位和已有名称冲突均在整批写入前拒绝，回读确认没有插入前面的有效行、没有覆盖旧名称。该工具目前仅覆盖商品；不是完整主数据或真实迁移验收。

```sh
.venv/bin/python scripts/phase0-migrate-masters.py phase0/migration/items-example.csv
.venv/bin/python scripts/phase0-migrate-masters.py phase0/migration/items-example.csv --apply
```

用 scripts/phase0-reconcile-opening.py 比较两个 UTF-8 CSV。样例为 phase0/migration/opening-example.csv。输入须先按公司与稳定业务键汇总。库存按商品、仓库及库存单位分组，应收应付按往来方分组，总账按科目分组。单位、币种或截止日期需要转换时，应先在受控映射表中确认，不能在比较时猜测。输入真实映射、导出与签名对账基准保存在仓库外。

```sh
.venv/bin/python scripts/phase0-reconcile-opening.py 源期初.csv 目标期初.csv
```

工具输出行数、缺失、新增和差异数量，拒绝重复键、非有限金额与不平衡试算。即使只有一分差异也要求复核，批准调整后重新导出比较。该工具核对汇总层；单据级未结明细、付款分配、外部引用幂等和两次导入恢复是 M1 后续验收项。
