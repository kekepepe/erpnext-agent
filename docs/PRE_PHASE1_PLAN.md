## P0.11 / M1：真实配置路径与迁移开发

### M1.1 将合成配置转为受控发布配置

现有 configure-release、configure-access 和 preflight 使用固定 R1 合成公司、example.invalid 用户和 localhost 边界；守卫还保留 P0 公司兼容例外。它们目前不能直接充当真实公司的发布包。

- 定义受控配置输入：目标环境/公司/仓库、真实身份与固定职能角色映射、会计科目、税模板适用性、UOM/价格/信用、编号和期间规则。沿用已冻结阈值，不重新发散设计。
- 通过原生配置或最小参数化装配路径落地，保留 dry-run、差异预览、配置冲突即停、目标环境校验、重放和审计。合成脚本继续限定在测试环境。
- 发布预检覆盖全部允许的公司与审批配置，拒绝 P0/R1 测试实体、测试身份及默认测试凭据；验证没有通过创建同名测试公司绕过守卫的可用路径。必要代码调整继续归属 P0，复验 C0 及 N2。
- 财务补验实际适用税模板、缺税/错税、含税/未税、折扣、退货税冲回、信用、关账期和重开权限。真实税务/账户资料由财务提供与确认，不能以任意合成 5%代替。

退出标准：独立发布样式站点使用另一套受控组织/身份映射可以重放配置，全部角色边界与审批负向检查通过，没有隐含测试名称依赖；财务预期结果可逐项追溯。

### M1.2 迁移映射与工具

- 确定切换截止时点、来源责任人、源到目标字段映射、清洗规则、唯一编码/外部引用、导入依赖、拒绝清单和人工处理责任。
- 迁移主数据、期初库存数量/价值、未结 AR/AP 及付款分配、必要期初 GL；明确应收应付明细与总账的重复计入防护。
- 已完成历史交易保留受控只读档案；未执行旧订单经审核后作为新批准订单关联旧编号。归档查询和保留责任写入 SOP。
- 交付版本化脱敏模板、校验器、dry-run 报告、批次清单、外部引用映射、导入日志、拒绝记录、幂等/断点处理和对账脚本。敏感资料、真实导出及凭据不得进入公开仓库。

### M1.3 两次隔离迁移与失败恢复演练

- 第一轮验证完整导入与对账；第二轮从干净起点证明可复现，并在已导入状态重放证明不重复记账。
- 测试重复编码、缺失关联、非法单位/币种、金额冲突、失败批次、超时后未知结果和中断恢复。未知写入结果先查询对账再重试。
- 失败时停止后续批次，按已演练路径恢复隔离快照/备份，不能删除已提交单据或直接改库伪装回退。
- 验收沿用冻结范围：物料×仓库数量差为 0；库存价值和 AR/AP 逐往来差不超过 CNY0.01；GL 借贷差为 0且匹配批准期初试算。任何舍入差都须有批准调整凭证，不静默容差放行。

退出标准：两次演练及一次失败恢复有完整证据，重放不新增重复交易，财务/库存/数据负责人签核逐项对账。handoff 的“至少一次”更新为冻结范围要求的“两次”。

## P0.12 / A1：发布候选包、恢复与 UAT

1. **A1.1 发布环境设计与重建。** 明确实际运行平台、资源/容量目标、站点隔离、持久存储、域名/TLS、秘密管理、监控日志、备份保留和运营责任。先形成可重复部署配置，再在隔离类生产环境从固定源与版本清单重建；现有 demo Compose 不作为生产方案。正式生产资源部署留在 Phase 1。
2. **A1.2 完整验收矩阵。** 在候选配置与迁移结果上验证采购到付款、销售到收款、退货/贷项、调拨/盘点、AR/AP/GL、七报表、九类审批、权限负向与审计；核对税费、折扣、期间边界和真实职能。完成1280×720与390×844操作清单、十类 PDF 逐页核对以及实时连接/断线重连。
3. **A1.3 安全和运行验收。** 核对生产身份/会话、权限、测试入口和测试数据排除、秘密及依赖清单、TLS/外部来源、日志与告警、队列/定时任务、磁盘/备份失效和约定容量。先约定业务量、可接受延迟、RPO/RTO，再实测，不能无依据宣称容量或恢复目标通过。
4. **A1.4 全站恢复和完整回退。** 使用原生备份/恢复运维入口，在另一隔离站点恢复数据库、公开/私有文件、必要配置/加密材料与匹配镜像；复核库存、AR/AP、GL、身份、权限、审批、审计、附件/PDF。演练失败部署后恢复上一套匹配镜像+配置+数据，记录实际耗时/数据窗口。升级与降级按受支持路径验证，不仅撤销展示源码补丁。
5. **A1.5 职能 UAT 与培训。** 采购、销售、库存、财务、审批人和管理员按真实职责完成正向/拒绝/异常及恢复流程；确认全退货净状态和避免重复发货。记录操作者、步骤、预期、结果、缺陷和签核。技术自动化证据不替代员工验收。
6. **A1.6 固定 RC 与评审。** 交付源码版本、镜像 digest、依赖/应用版本、配置清单、迁移包、校验值、验收索引、已接受限制、部署/切换/烟测/回退手册、支持升级路径和实名责任表。全部阻断项关闭或显式批准例外，再取得部署就绪批准。

退出标准：全部 Must 有对应通过证据，迁移与恢复对账签核，类生产重建可复现，RC 可唯一识别且可回退，部署/运营负责人到位，项目所有者明确批准进入 Phase 1。验收后若改业务逻辑、配置契约、报告或迁移代码，形成新 RC 并复验受影响项。
