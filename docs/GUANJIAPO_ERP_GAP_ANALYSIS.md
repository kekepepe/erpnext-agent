# 网上管家婆与本地 ERP 功能差距

**对照日期** 2026 年 11 月 22 日
**对照对象** Chrome 中实际打开的网上管家婆进销存云服务与本地 ERPNext v16 中文工作台

两套系统都覆盖商品、订单、出入库和收付款。实际操作差距最大的是**出入库时是否同时处理结算、多个价格来源如何决定最终报价，以及录单时能否即时核对含税金额**。先确认这些差异，才能判断哪些需求需要改代码，哪些用原生能力配置即可。

管家婆证据来自首页流程图、采购入库和销售出库表单、两种价格策略面板、客户资料和库存及财务菜单，商品基本字段另参考用户提供的截图。页面只供查看，未录入数据或执行保存、过账或配置修改。菜单名称证明入口可见，空白表单证明字段和操作可见，规则帮助说明其设计行为。本文不据此推定当前启用状态、实际成交价、会计凭证或岗位权限。ERP 侧以本机浏览器、容器内原生对象定义和项目验收记录为依据。

## 采购、销售和结算

| 功能 | 管家婆页面所见 | 本地 ERP 的对应能力与差距 |
|---|---|---|
| 采购入库如何产生应付 | 首页流程标注采购入库增加库存和应付。入库单可直接开单或选来源，表尾可用预付款、录付款账户，并列出本单、此前、合计应付。 | **已支持，流程不同。** 首版由订单生成入库以处理实物，财务再建采购发票确认应付，由付款单核销。收货环节也可能产生暂估库存会计分录。一个入库页面直接完成结算、查看往来余额的操作尚未集成。 |
| 销售出库如何产生应收 | 首页标明可直接开单、可按单结算，出库关联欠款、毛利和库存。表尾可用预收款、录收款信息，并列出本单、此前、合计应收。帮助区说明了订单专款。 | **已支持，流程不同。** 首版以已批准订单办出库，财务用销售发票确认应收，收款单核销。原生付款单有交易引用和未分配金额字段。出库即办收款、订单专款自动带入和同屏余额提示没有同等的已验收流程。 |
| 下游单据从哪里选来源 | 采购入库可选订单或询价单，销售出库可选订单或报价单。 | **部分对应。** ERP 已验证从采购/销售订单生成入库/出库及分批办理。销售报价转销售订单已有路径。原生存在询价请求和供应商报价，工作台尚未集成采购询比价链路。管家婆两种跳过订单的来源选择与 ERP 首版的订单审批及收发货关联要求有实质差异。 |
| 退货、冲账和退款 | 采购、销售菜单分别提供退货入口。 | **已支持，流程不同。** 工作台将实物退货、发票冲回和实际退款分开，支持追溯原单。管家婆本轮仅查看退货入口，退货过账、退款方向和冲账规则待确认。 |
| 运费、费用入成本和物流 | 入库表单有物流公司、运单、运费、运费付款和分摊入成本选项。销售出库有买家运费、按规则计算、运费分摊、物流代收及物流单打印入口。其中代收控件在所查看空白单上不可用。 | **原生能力部分覆盖。** ERP 原生到岸成本凭证、运输规则和货运单可作为候选，当前工作台未集成同屏运费结算、入成本选择和代收链路。这几项需要分别验收费用是否进入存货、是否形成往来余额、代收回款如何核销。 |
| 开票与打印 | 入库和出库表单可选是否需要开票。入库有发票类型、抬头及税号等字段，还有条码打印和打印样式入口。 | **部分对应。** ERP 已有财务单据、十类受控中文业务 PDF，可用附件和备注关联法定发票。首版未交付税务开票集成、按单开票需求工作流或同等的条码与物流标签打印验收。看到管家婆开票字段并不能确认实际税务平台对接。 |

## 商品、价格和录单

| 功能 | 管家婆页面或参考图所见 | 本地 ERP 的对应能力与差距 |
|---|---|---|
| 商品规格、单位及中英文资料 | 商品参考图有分类、类型、规格、型号、品牌、单位和多单位开关。入库表格可见商品简称、规格和型号等列。 | **已覆盖主要字段。** ERP 已有规格、型号、简称、品牌、主单位和多单位换算，原生单据行显示商品核对信息。英文品名和要求是 ERP 本轮新增的业务字段。两套系统如对同一包装分别使用“盒”和“箱”，迁移应按含量映射并核对价格单位。 |
| 商品成本和标价 | 参考图的新增商品有成本算法、参考成本、采购价、最低售价、零售价和预设售价。所示成本算法为全月一次加权平均。 | **部分对应。** ERP 五档销售价及采购价通过价目表和商品价格维护，参考成本和最低售价记录已实现。当前最低售价字段仅供参考，尚无与旧系统等效且已验收的限制流程。ERP 合成基线使用移动平均，两种成本算法会影响出库成本和毛利，属于财务口径差异。截图不能确定旧系统各商品实际使用哪种算法。 |
| 客户报价档位 | 客户资料分别有价格等级、销售整单折扣、数量阶梯开关及查看商品售价入口。 | **基础档位已实现。** ERP 已实测一位客户选一个默认档位后自动取价。原生价格规则有数量、时间、客户和优先级字段。客户整单折扣、数量阶梯与档位价同时命中时的计算和顺序尚未按业务场景配置验收。 |
| 销售价格从哪里来 | 销售价格策略可按优先级排列客户价格本、客户价格折扣跟踪、价格等级及往来单位销售折扣。跟踪可设最近天数，也有是否跟踪确认订单价格的设置。 | **功能差距。** 当前 ERP 主路径按客户默认价目表取价，没有交付同等的客户专价、历史成交、客户折扣、档位价统一优先级配置和来源提示。原生价格规则可作为候选，历史价格的取值时点和有效窗口需要单独核对。 |
| 采购价格从哪里来 | 采购价格策略可按优先级排列供应商价格折扣跟踪、供应商价格本、商品采购价与供应商整单折扣。帮助对订单转入库后改价是否进入跟踪有说明。 | **功能差距。** ERP 首版已有采购价目表。供应商专价、最近成交与默认采购价冲突时采用哪一项，收货改价是否影响下次采购，这套组合规则尚未集成验收。 |
| 商品表格和金额预览 | 入库表格集中显示行级含税单价、含税金额、税率、折后不含税单价，页面另有整单折扣、优惠分摊和字段设置。 | **部分对应。** ERP 原生商品表格可编辑，补充的核对表显示规格、单位、折扣和含税金额。行级含税结果目前保存后显示，折算税费率也可能包含计入总额的应计费用，和法定税率是两个口径。两套系统的整单优惠分摊、含税倒算及尾差处理仍需用同一单据验证。 |
| 快速录单和业务默认值 | 入库与出库页面集中提供扫码、导入商品、选来源、字段设置、开单默认设置。客户资料另有经手人、销售税率、交货方式、默认物流和默认开票。 | **部分对应。** 本地采购订单可见扫码、批量添加、上传和表格设置。尚未验收旧表格导入映射、单据级默认配置，以及客户资料到不同单据的自动带入。税率应核对税模板规则，部门与经手人应先明确岗位和组织口径。 |

## 库存、财务与报表

| 功能 | 管家婆页面所见 | 本地 ERP 的对应能力与差距 |
|---|---|---|
| 调拨与盘点 | 库存菜单有调拨订单、调拨单、盘点记录、分仓库存及库存变动统计。 | ERP 已验证直接调拨、盘点调整、库存余额和流水，工作台尚未交付独立的调拨订单队列。是否需要先申请再执行，取决于仓库当前作业。 |
| 补货、组装与成本统计 | 采购菜单有智能补货。库存菜单有生产组装分类及全月商品出库成本表入口。 | 现有工作台没有已验收的同等入口。组装属于当前首版范围之外。补货和全月成本统计需要先确定实际使用频率与计算口径。 |
| 往来、账务和经营报表 | 财务菜单有收付款、费用单、往来单位应收应付、开票公司管理等入口。销售与采购菜单有单据、明细、统计及销售毛利入口。 | ERP 有收付款和资金转账、原生库存/采购/销售/应收/应付/总账七类报表。当前缺口主要在分类入口和口径对齐，例如本单与前欠合计、旧版采购销售明细导出、毛利按出库还是按发票统计，以及费用分摊是否计入毛利。单独的费用单和开票公司管理不属于已验收工作台功能。 |
| 客户和供应商资料管理 | 客户和供应商共用一张资料列表，提供导入新增、批量地址、启用停用和期初应收应付入口。 | ERP 分设客户、供应商、联系人和地址，已有合成主数据导入及逐发票期初核销验证。旧系统的双身份往来单位、地址批量映射和同屏期初录入属于迁移与工作台差异。 |

## 验收先后

1. **先对账，再决定是否合并操作。** 用同一批采购和销售样例，记录各动作前后的库存、应收应付、已收已付和总账。覆盖现结、赊账、部分预收预付、分批收发及退货。重点确认用户需要用一个入口串联步骤，还是要求收发货与结算在同一次业务动作完成。
2. **做一张取价对照表。** 对同一商品分别设置客户/供应商专价、最近成交价、默认档位、数量阶梯和整单折扣。每个场景记录应选价格、来源、生效日期、单位及最终金额。由采购、销售确认优先级后，再决定原生配置和需补的功能。
3. **核对价格显示与费用口径。** 以含税录入、折扣、批量导入和运费入成本为样例，核对逐行与整单金额精确到分，区分法定税率、折算税费率和运输费用。条码、物流打印与批量配置按现场使用频率评估。
